# cbox skills catalog

These public, vendor-neutral skills help coding agents work with `cbox`. They
are project assets, not part of this repository's internal Eidolons setup.

| Skill | Purpose |
|---|---|
| [`cbox-boxfile`](cbox-boxfile/SKILL.md) | Inspect a project and compose a parser-valid `Boxfile.toml` |

Release archives preserve the `skills/<name>/` directory. See the main
[README](../README.md#coding-agent-skill) for checksum-first installation.
